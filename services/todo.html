오늘 해야 할 일을
간단하게 기록하고 정리하세요

AIRPALAB 오늘의 할 일 관리는 복잡한 프로젝트 관리보다 하루 단위의 업무와 개인 할 일을 빠르게 기록하고 확인하는 데 초점을 둔 웹 To-Do 서비스입니다. 작업 추가, 검색, 완료 상태 필터, 완료 작업 정리와 남은 작업 수 확인 기능을 제공합니다.

서비스 한눈에 보기

빠른 작업 등록
새 작업을 입력해 오늘 해야 할 항목을 목록으로 관리할 수 있습니다.

작업 검색
목록이 길어져도 검색 입력창을 이용해 필요한 작업을 찾을 수 있습니다.

상태 필터
전체·미완료·완료 항목을 구분해서 볼 수 있습니다.

편의 기능
완료된 작업 일괄 삭제, 남은 작업 수 표시, 다크 모드와 Google 로그인 인터페이스를 제공합니다.

Features

주요 기능

공개된 AIRPALAB To-Do 화면에서 확인할 수 있는 사용자 기능을 중심으로 정리했습니다.

새 작업 추가해야 할 일을 짧은 문장으로 입력해 목록에 추가합니다.
작업 검색검색 입력창으로 등록된 항목 중 필요한 내용을 빠르게 찾습니다.
전체·미완료·완료 필터현재 보고 싶은 작업 상태만 선택해 목록을 단순하게 유지할 수 있습니다.
완료된 작업 삭제끝난 항목을 한 번에 정리해 오늘 필요한 작업에 집중할 수 있습니다.
남은 작업 수아직 완료하지 않은 작업이 몇 개인지 화면에서 확인할 수 있습니다.
다크 모드와 로그인다크 화면 전환 버튼과 Google 계정으로 시작할 수 있는 로그인 UI를 제공합니다.
How to Use

기본 사용 흐름

  1. 오늘 해야 할 일을 입력합니다.
    ‘보고서’보다 ‘보고서 목차 수정’처럼 행동이 보이는 문장으로 적으면 실행하기 쉽습니다.
  2. 작업을 완료하면 상태를 변경합니다.
    미완료 목록에서 남은 작업에 집중할 수 있습니다.
  3. 필터와 검색으로 목록을 좁힙니다.
    항목이 많아졌을 때 전체 목록을 계속 훑는 대신 필요한 상태나 검색어를 사용합니다.
  4. 완료된 작업을 정리합니다.
    완료 항목이 너무 많이 쌓이면 일괄 삭제 기능으로 화면을 간결하게 유지할 수 있습니다.
Daily Routine

하루 단위로 활용하는 방법

아침에는 반드시 끝낼 일 1~3개를 먼저 등록하고, 업무 중 새로 생긴 일은 짧게 추가합니다. 저녁에는 남은 작업을 다음 날로 그대로 넘기기보다 정말 필요한지 다시 판단해 삭제·연기·재정의하는 편이 좋습니다.

작업을 작게 표현하세요.
‘홈페이지 수정’처럼 큰 표현보다 ‘메인 소개 문구 수정’, ‘오목 상세 페이지 링크 확인’처럼 한 번에 실행할 수 있는 단위가 시작하기 쉽습니다.

Why Simple

복잡한 프로젝트 관리보다 빠른 실행에 초점

결정 피로 줄이기

항목이 너무 많으면 무엇부터 할지 결정하는 데 시간이 듭니다. 필터를 이용해 현재 필요한 일만 보는 것이 도움이 됩니다.

완료 상태 가시화

한 일을 완료 상태로 표시하면 남은 양이 명확해지고 하루의 진행 상황을 쉽게 확인할 수 있습니다.

검색으로 빠르게 찾기

작업 이름을 구체적으로 적어 두면 목록이 길어져도 검색을 통해 관련 항목을 빠르게 찾을 수 있습니다.

Account & Privacy

로그인과 데이터 사용 시 확인할 점

중요한 자료는 별도로 백업하세요.
웹 To-Do 도구의 저장 방식은 서비스 버전과 로그인 상태에 따라 달라질 수 있습니다. 장기 보존이 필요한 업무 기록이나 유일한 원본 문서는 별도의 신뢰할 수 있는 저장소에도 보관하는 것을 권장합니다.

현재 서비스 화면에는 Google 로그인 기능이 제공됩니다. 계정 기능을 사용할 때는 서비스가 안내하는 개인정보 처리 방식과 로그인 상태를 확인하고, 공용 기기에서는 사용 후 로그아웃하는 것이 좋습니다.
