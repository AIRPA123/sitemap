AIRPALAB 지뢰찾기 프리미엄은 별도 설치 없이 웹 브라우저에서 바로 실행할 수 있는 지뢰찾기 게임입니다. 글래스모피즘 기반의 다크 UI, 첫 번째 클릭 안전 보장, 빈칸 자동 확장, 3단계 난이도와 모바일 조작을 제공합니다.

서비스 한눈에 보기

첫 클릭 안전 보장
처음 클릭한 셀과 주변 8개 셀에는 지뢰를 배치하지 않습니다.

자동 빈칸 확장
주변 지뢰가 없는 0 셀을 열면 연결된 빈 영역이 자동으로 펼쳐집니다.

3가지 난이도
초급 9×9·10개, 중급 16×16·40개, 고급 16×30·99개 지뢰를 지원합니다.

모바일 지원
좁은 화면에서는 셀 크기가 자동으로 줄어들며 길게 터치해 깃발을 설정할 수 있습니다.

Key Features

주요 기능

현재 지뢰찾기 프로젝트에 구현된 핵심 기능을 실제 설명 중심으로 정리했습니다.

Premium Glassmorphism UI반투명 패널, 다크 배경, 네온 계열 텍스트 효과와 부드러운 애니메이션으로 현대적인 화면을 구성했습니다.
Safe Start첫 클릭 좌표와 주변 8칸을 지뢰 배치 대상에서 제외해 시작하자마자 게임이 끝나는 상황을 막습니다.
Flood Fill 자동 확장주변 지뢰가 0개인 셀을 열면 인접한 빈 공간을 재귀적으로 탐색해 여러 칸을 한 번에 엽니다.
난이도별 보드 설정초급·중급·고급으로 보드 크기와 지뢰 개수가 달라져 단계적으로 난이도를 높일 수 있습니다.
게임 오버 연출지뢰를 밟으면 모든 지뢰가 짧은 무작위 딜레이를 두고 흔들리며 나타나는 효과를 적용했습니다.
반응형 레이아웃600px 이하 화면에서는 셀 크기와 레이아웃이 조정되어 모바일에서도 보드를 사용할 수 있습니다.
Difficulty

난이도 선택

각 난이도는 보드 크기와 지뢰 수가 달라집니다.

Easy초급

9 × 9 그리드
지뢰 10개

처음 규칙을 익히고 숫자 힌트를 읽는 연습에 적합합니다.

Medium중급

16 × 16 그리드
지뢰 40개

보드가 넓어지면서 여러 숫자 조건을 함께 비교해야 하는 경우가 많아집니다.

Hard고급

16 × 30 그리드
지뢰 99개

더 넓은 탐색 공간과 높은 지뢰 밀도로 장시간 집중과 정확한 추론이 필요합니다.

How to Play

조작 방법

좌클릭
타일을 엽니다. 안전한 셀이면 주변 지뢰 개수 1~8이 표시되고, 주변 지뢰가 0개라면 인접 영역이 자동으로 펼쳐집니다.
우클릭
지뢰로 의심되는 닫힌 셀에 깃발을 꽂거나 제거합니다. 깃발 수에 따라 남은 지뢰 개수 표시도 변합니다.
모바일 길게 터치
모바일에서는 셀을 길게 터치하여 우클릭과 같은 깃발 기능을 사용할 수 있습니다.
초기화
상단 새로고침 버튼 또는 게임 종료 후 다시 하기 버튼을 눌러 새 게임을 시작합니다.
Game Logic

기본 게임 원리

숫자는 해당 셀을 둘러싼 최대 8개 셀 중 지뢰가 몇 개 있는지를 나타냅니다. 숫자를 보고 지뢰가 확실한 위치에는 깃발을 표시하고, 지뢰가 없다고 확신할 수 있는 칸을 차례로 열어 가는 것이 핵심입니다.

초보자 팁
한 숫자만 보고 판단하지 말고 서로 인접한 숫자의 조건을 비교해 보세요. 이미 필요한 지뢰 수가 모두 확인된 숫자 주변의 다른 닫힌 칸은 안전한 칸일 가능성을 논리적으로 확정할 수 있습니다.

Technical Details

기술적 구현의 핵심

프로젝트 README에 설명된 JavaScript와 CSS 구현 방식입니다.

첫 클릭 보호 로직

첫 클릭 좌표를 기준으로 행과 열의 거리가 1 이하인 모든 셀을 지뢰 배치에서 제외합니다. 클릭한 셀을 포함해 최대 9칸이 안전 구역이 됩니다.

재귀적 Flood Fill

열린 셀의 주변 지뢰 수가 0이면 상하좌우와 대각선의 인접 셀을 재귀적으로 확인하면서 안전 영역을 자동으로 확장합니다.

글래스모피즘 디자인

CSS 변수, 반투명 배경, backdrop-filter, 부드러운 그림자와 애니메이션을 조합해 깊이감 있는 다크 게임 UI를 구현했습니다.

사용 기술
HTML5로 구조를 만들고, Vanilla CSS로 테마와 반응형 디자인을 구성하며, JavaScript ES6로 게임 상태, DOM 조작, 랜덤 지뢰 배치와 재귀 탐색 로직을 처리합니다.

지뢰찾기를 처음 시작한다면

처음에는 빠르게 많은 칸을 여는 것보다 숫자가 의미하는 조건을 정확히 이해하는 것이 중요합니다. 숫자 주변의 닫힌 칸 수와 이미 표시한 지뢰 수를 비교하면 안전한 칸을 체계적으로 찾을 수 있습니다.
