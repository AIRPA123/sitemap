Fun Game · Memory Matching

보기 쉽고 듣기 편하게,
사용자 실력에 맞춰 변하는 기억력 게임

AIRPALAB 기억력 매칭 게임은 노년층 접근성과 사용자 친화적인 경험을 우선해 설계한 카드 기억력 웹게임입니다. 큰 글씨와 명확한 대비, 한국어 음성 안내, 최근 게임 결과를 반영한 자동 난이도 조절, 브라우저 기반 성과 기록 기능을 제공합니다.

기억력 게임 바로 실행 →활용 가이드 읽기

서비스 한눈에 보기

접근성 중심 UI
큰 글씨, 명확한 대비, 큼직한 3D 카드와 친절한 상태 메시지를 사용합니다.

한국어 음성 안내
게임 시작, 성공·실패, 시간 초과와 난이도 변경을 Web Speech TTS로 안내합니다.

적응형 난이도
최근 3회의 게임 결과를 분석해 쉬움·보통·어려움 사이에서 난이도를 자동 조정합니다.

최근 기록
게임 결과를 브라우저 localStorage에 저장하고 최근 7회의 성과를 확인할 수 있습니다.

Key Features

주요 기능

기억력 게임 프로젝트에 구현된 접근성·음성·기록 기능을 중심으로 정리했습니다.

노년층 친화적 디자인돋보기 없이도 보기 편하도록 글씨 크기와 대비를 높이고 카드 조작 영역을 크게 구성했습니다.
3D 카드 뒤집기마우스 클릭 또는 터치로 카드를 뒤집을 수 있으며 CSS 3D Perspective 애니메이션을 적용했습니다.
한국어 TTSWeb Speech Synthesis API로 진행 상황을 음성으로 안내하며 우측 상단 토글로 켜고 끌 수 있습니다.
자동 난이도 조절최근 3회 중 2회 이상 성공하면 한 단계 올리고, 실패가 많으면 한 단계 낮춰 적절한 자극을 유지합니다.
실시간 통계경과 시간, 시도 횟수와 현재까지 맞춘 카드 쌍을 게임 중 바로 확인할 수 있습니다.
최근 7회 성과난이도, 성공 여부, 소요 시간, 시도 횟수와 일시를 브라우저에 기록해 최근 성과를 보여줍니다.
Difficulty

3단계 난이도와 자동 조정

카드 수가 늘어날수록 기억해야 할 위치와 조합이 많아집니다.

Easy쉬움

4쌍 · 총 8장

게임 방식과 카드 위치 기억에 익숙해지는 단계입니다.

Normal보통

6쌍 · 총 12장

더 많은 위치를 기억하면서 전략적인 카드 선택을 연습할 수 있습니다.

Hard어려움

8쌍 · 총 16장

더 넓은 위치 정보를 유지해야 해 집중과 관찰이 더 많이 필요합니다.

자동 조정 원리
최근 완료한 3번의 게임 결과를 분석해 성공이 2회 이상이면 난이도를 한 단계 높이고 실패율이 높으면 낮춥니다. 사용자는 매번 난이도를 직접 바꾸지 않아도 최근 성과에 맞춰 게임을 이어갈 수 있습니다.
How to Play

게임 진행 방법

  1. 난이도에서 게임을 시작합니다.
    카드들이 뒤집힌 상태로 배치됩니다.
  2. 카드 두 장을 차례로 선택합니다.
    같은 그림이면 매칭 성공으로 유지되고, 다르면 다시 뒤집힙니다.
  3. 이전에 본 카드 위치를 기억합니다.
    실패한 시도도 다음 선택을 위한 위치 정보가 됩니다.
  4. 모든 카드 쌍을 찾으면 완료됩니다.
    결과는 최근 성과 기록에 저장되고 다음 난이도 조정에 활용됩니다.
Time & History

제한 시간과 기록

각 난이도에는 기준 시간이 있으며 기준 시간의 1.5배를 넘기면 시간 초과로 처리합니다. 예를 들어 README에 제시된 보통 난이도는 최대 180초까지 진행될 수 있습니다.

브라우저 저장 정보

게임 결과의 난이도, 성공 여부, 소요 시간, 시도 횟수와 일시가 localStorage에 저장됩니다. 기록 지우기 기능을 이용해 최근 성과 데이터를 초기화할 수 있습니다.

Accessibility

접근성을 고려한 조작과 안내

스크린 리더 안내

aria-live, aria-label, aria-pressed 등을 이용해 카드 상태와 게임 진행 정보를 보조기술에 전달하도록 설계했습니다.

키보드 내비게이션

마우스 없이 Tab으로 요소를 이동하고 Enter 또는 Space 키로 카드를 뒤집거나 제어 기능을 사용할 수 있습니다.

포커스 표시

키보드로 이동 중인 요소를 쉽게 찾도록 고대비 포커스 링을 제공합니다.

음성 안내 토글

음성이 필요하지 않은 사용자는 언제든지 TTS 안내를 끌 수 있습니다.

Technology

사용 기술

HTML5 접근성 마크업

스크린 리더와 키보드 사용자를 고려한 ARIA 속성과 의미 있는 UI 상태를 제공합니다.

CSS3 3D 카드

Custom Properties, Flexbox/Grid와 Perspective Flip 애니메이션으로 카드 전환 효과를 구성합니다.

Vanilla JavaScript

게임 상태, 자동 난이도, LocalStorage API와 Web Speech Synthesis API를 별도 프레임워크 없이 처리합니다.
