웹 브라우저에서 바로 즐기는
2인용 오목 게임

AIRPALAB 오목은 HTML5, CSS3, JavaScript로 제작된 2인용 웹 오목 게임입니다. 별도 설치 없이 브라우저에서 실행할 수 있으며, 15×15 바둑판과 흑·백 교대 플레이, 최근 착수 표시, 승리 판정과 재시작 기능을 제공합니다.

서비스 한눈에 보기

게임 방식
한 기기에서 두 사람이 흑돌과 백돌을 번갈아 두는 방식입니다.

바둑판
15×15 격자와 9개의 화점을 적용했습니다.

승리 조건
가로·세로·대각선 중 같은 색 돌이 5개 이상 연속되면 승리합니다.

현재 규칙
33·44·장목 등 금수는 아직 적용하지 않은 일반 오목 방식입니다.

Features

주요 기능

README에 정리된 실제 구현 내용을 기준으로 현재 제공되는 기능을 요약했습니다.

15×15 표준 바둑판15개의 행과 열로 구성된 격자형 바둑판에서 플레이합니다.
9개 화점 표시바둑판의 위치를 쉽게 파악할 수 있도록 기준점 역할을 하는 화점을 배치했습니다.
입체적인 흑돌·백돌CSS radial-gradient를 이용해 단색 원보다 실제 돌에 가까운 입체감을 표현했습니다.
최근 착수 위치 표시가장 최근에 놓인 돌 중앙에 붉은 표시가 나타나 직전 수를 쉽게 찾을 수 있습니다.
실시간 차례 안내상태 영역에서 현재 흑돌 차례인지 백돌 차례인지 확인할 수 있습니다.
승리 모달과 재시작승리 조건이 충족되면 결과를 안내하고 바로 새 게임을 시작할 수 있습니다.
How to Play

게임 방법

  1. 게임 시작
    페이지를 열면 흑돌이 선공으로 시작합니다.
  2. 돌 놓기
    비어 있는 바둑판 교차점을 클릭하여 돌을 놓습니다.
  3. 교대 플레이
    흑돌과 백돌이 한 번씩 번갈아 착수합니다.
  4. 최근 수 확인
    마지막에 놓인 돌에는 붉은 점이 표시됩니다.
  5. 승리 판정
    가로·세로·두 대각선 중 한 방향으로 같은 색의 돌이 5개 이상 연결되면 승리합니다.
  6. 재시작
    상단 재시작 버튼 또는 승리 모달의 다시 하기 버튼으로 새 판을 시작할 수 있습니다.
Rules

현재 적용되는 오목 규칙

현재 버전은 금수 규칙을 적용하지 않은 일반 오목 방식입니다. 흑돌이 먼저 두며, 어느 색이든 같은 방향으로 돌이 5개 이상 연속되면 승리로 판정합니다.

알아두세요.
렌주 규칙에서 사용하는 33, 44, 장목 등의 흑돌 금수는 현재 버전에는 적용되지 않았습니다. 따라서 공식 대회 규칙과는 차이가 있을 수 있습니다.

친구나 가족과 한 기기에서 가볍게 두는 웹게임을 목적으로 하며, 규칙이 단순해 오목을 처음 접하는 사용자도 바로 시작할 수 있습니다.

Technical Highlights

기술적으로 어떻게 구현했나요?

오목 서비스의 화면 구성과 승리 판정은 비교적 단순한 웹 기술로 구현되어 있습니다.

CSS Grid 기반 15×15 보드

CSS Grid로 15×15 셀을 배치하고 각 셀의 가상 요소를 이용해 교차선을 표현합니다. 돌은 셀의 중심에 놓이도록 배치됩니다.

radial-gradient 바둑돌

흑돌과 백돌에 방사형 그라데이션을 적용해 빛이 비치는 둥근 바둑돌처럼 보이도록 표현했습니다.

마지막 착수 중심 판정

매번 전체 바둑판을 모두 확인하기보다 마지막으로 놓인 돌을 기준으로 가로, 세로, 두 대각선의 연속 돌을 확인합니다.

승리 판정의 핵심
마지막 착수 지점에서 4개 방향을 확인하고, 각 방향의 양쪽에서 같은 색 돌이 몇 개 연속되는지 계산합니다. 연속 개수가 5개 이상이면 승리로 처리합니다.
Roadmap

향후 개선할 수 있는 기능

아래 항목은 현재 제공되는 기능이 아니라 README에 정리된 향후 개선 아이디어입니다.

33·44·장목 금수 규칙

흑돌 선공의 유리함을 완화하는 일반 오목·렌주 계열의 금수 규칙을 추가할 수 있습니다.

무르기 기능

직전 착수를 취소하고 한 수 되돌리는 편의 기능을 추가할 수 있습니다.

AI 대전

미니맥스 또는 휴리스틱 평가 함수를 이용해 컴퓨터와 대국하는 모드를 확장할 수 있습니다.

온라인 1:1 대전

WebSocket 또는 WebRTC 기반 실시간 네트워크 대전 기능으로 확장할 수 있습니다.
